# 通用问题求解引擎

这是一个多 Agent 工作台。给出目标、资料和完成条件，Agent 在独立的任务环境里调查、保存证据、协作并交付结果。可以用来核对资料、分析数据、验证假设或诊断软件。任务提供领域信息和范围，平台提供协作、执行和复盘。

| 协作模式 | 如何工作 | 如何判断完成 |
| --- | --- | --- |
| 黑板探索 | Explore 提交有依据的发现（Fact）和待探索方向（Intent）；Derive 根据缺口提出下一步 | Close 依据原验收条件和当前证据逐项裁定，交付结论与缺口 |
| 原生 CTF | Lead 管理题目与分工，Worker 在当前 Assignment 的范围内协作，记录进展和候选结果 | 成员结束、候选和可信验证分别记录；Lead 按原任务要求收尾 |

黑板工作台可在协作黑板和成果树之间切换。成果整理 Agent 归纳已记录的发现、尝试和缺口，并给出可追溯的来源；可在成果树中追问。整理有独立额度，不扣原求解预算，不改变 Close 的裁定。CTF 使用团队工作台，按题目和 Agent 查看记录。

两种模式共用平台账号、Pi 会话层、OpenSandbox 执行环境、模型目录和运行容量；任务的执行环境、资料、会话和费用各自独立。新任务使用 USD；历史金额和币种按原账本保留。在模型管理中维护 OpenAI 兼容服务，在独立的 MCP 管理页维护外部工具，角色权限以任务创建时冻结的配置为准。
