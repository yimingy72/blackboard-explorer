# 前端视觉与交互规范

依据：PRODUCT.md与用户批准的B2工作台及顶部Goal设计（2026-10-10）。本规范统一正式前端；运行机制和领域规则仍以docs/design/为准，实施范围见docs/tasks/UI-rebuild.md。

## 视觉方向

采用浅色、蓝色主要操作的产品工作台。紧凑左导航与浅灰工作面承托白色内容面板，深色正文使用系统字体；密度通过减少重复标题和容器padding获得，不缩小主要内容。图谱作者颜色属于数据编码，与品牌色分开，状态同时使用文字、图形和颜色。

## 组件与样式来源

- Ant Design 6.6.5提供通用控件、Listy、Table、Form、Tabs、Segmented、Skeleton、Modal、Drawer、Dropdown、Collapse、Upload、Tree等；Ant Design X 2.9.0提供Bubble、Sender、Think、ThoughtChain等聊天呈现。
- Ant Design Icons 6.3.4统一动作图标；图标按钮保留可访问名称，不以emoji或字体符号充当主要动作图标。
- 单一根级XProvider继承ConfigProvider主题与国际化，antd App提供上下文内反馈。优先全局token、组件token、公开styles/classNames；CSS Module补业务布局、画布和阅读排版，不覆盖内部.ant-*结构。
- 保留React18、Vite、Query、Router和ReactFlow；react-resizable-panels 4.14.3负责成熟的拖动与键盘调宽。无需Pro、Next、新模型SDK、网络字体或复杂主题切换。

## 文字与控件

- 表单和控件正文以14px为基准，长篇内容14–15px；辅助文字和图谱元数据不低于12px。代码与原始记录使用系统等宽字体。
- 蓝色实底用于主要操作，中性色用于次级操作，删除/失败使用危险语义色。保留组件hover、focus、active、disabled、loading、error状态，不只换颜色而遗漏行为。
- 桌面使用紧凑标准尺寸，手机主要触控区44px、输入16px以避免系统自动放大。密码显示切换、错误关联和凭据保存保持原流程。
- 受控字段保持服务端校验和草稿；Select、Checkbox、Switch等按真实API绑定。配置快照与版本冲突不因重构自动覆盖。

## 应用框架与页面

- 可展开左导航集中提供任务列表、新建任务、配置中心和最近任务，窄屏使用导航Drawer。顶栏避免重复页面切换，右上只保留账户及必要上下文操作。
- 手机隐藏固定窄侧栏，导航按钮放在顶栏，给列表与表单留出完整宽度；关闭Drawer或切回桌面断点后，焦点回到可见的导航按钮。
- 根地址进入任务列表。全局导航保持“任务 / Agent 配置”，详情归属“任务”；进入或退出任务不会插入新的“协作画布”菜单。
- 模型/MCP配置采用紧凑连接/保存工具栏和清楚的核心字段分组，计费与低频信息折叠。Worker/CTF角色选择与保存同栏，提示词与工具桌面并排、窄屏单列；调度和变量按需展开。
- 创建任务保留内容与运行设置两区。列表、设置、报告统一标题、间距、控件与反馈；列表优先名称和短ID，模式/运行状态/已记录费用与预算/耗时分明。终态显示“已结束”，未知费用不补零；手机使用纵向记录直接显示信息与操作。列表搜索和页码写入URL，详情与报告往返保持查找位置。
- 首页使用分页Listy，不为20条记录开启虚拟滚动；任务名与短ID同组，状态同时提供图标、文字和浅底。全部/进行中/已结束/异常使用Segmented并只显示一处总数，筛选、搜索与页码保存在URL。报告和删除收进每行操作菜单；删除取消回到原行操作，删除成功回列表标题。中等宽度仍保留模式、费用、预算、耗时和创建时间。
- 保存操作保持可见，手机避免浮动栏遮挡输入；短屏允许正常滚动，不把主要阅读区压到不可操作。
- 配置页未保存时，内部导航和浏览器返回须先确认；保存进行中不能放弃正在写入的操作，成功后可继续已请求的跳转。已有浏览器关闭保护保留。保存后再次编辑立即清除旧成功提示；加载、空配置和请求失败分别呈现。
- 模型价格是必填内容，新建模型默认展开；验证失败展开并聚焦无效字段。旧非人民币价格只供参考，要求重新填写人民币单价，不直接改币种标签。MCP 连接未保存时不读取旧版本工具清单。
- 缺少可用模型时，新标签页直接打开模型配置；新建任务页保留目标和附件，返回后可刷新模型列表。历史工作区的目录、预览、缓存和归档下载均以所选轮次为准；报告正文与任务元信息分别恢复错误。

## 画布、详情与Goal

- 默认完整画布。选择Agent直接进入连续会话，选择题目进入概览/解题流程/文件，不恢复默认公开活动页签。题目A方案只保留单一题名，状态以图标、文字、浅底和边框同时表达；已交付与可信已解出分开。详情面板可调宽、放大/还原、关闭与Esc，窄屏在工作区内全宽展示。断点只改变布局，不卸载当前会话；阅读、推理/工具展开及草稿保持。窄屏详情覆盖画布时，底层画布inert，不能进入不可见的键盘焦点。
- 顶部“目标”在画布列内就地展开，默认收起。原目标正文优先，完成要求或验收条件其次，初始附件紧凑侧置；背景/约束折叠，长目标可展开全文。缺字段不编造摘要、TODO或结论。
- Goal开合不改变选择、草稿、Session或画布transform。窄屏暂时隐藏会话时保留其状态，收起目标后恢复；附件预览退出后保留Goal展开状态。
- 保留用户平移、缩放和节点位置；轮询、选中与面板开合不重置已操作的视角。普通黑板沿用增量布局；CTF按下述环绕规则处理。容器尺寸变化不自动重设视角；首次布局及尚未操作时的新增拓扑可适配，用户选择节点后也应保留视角。已有节点坐标保留，只布置新增节点；大型ELK引擎按实际布局需要加载。
- 弹窗和浮层采用组件的焦点、遮罩、层级与关闭行为。保留取消、Esc和触发焦点恢复，关闭面板不抢走用户已经转向其他控件的焦点。
- CTF使用用户于2026-10-13认可的明亮环绕协作：Lead位于中心，成员在内圈、题目向外展开，同题只出现一次。成员到题目保持主责实线、协作短虚线，Lead团队关系按选中或实际派发事件显示；光束只由已加载基线之后的真实更新触发，首次打开不重播历史，不把结构线冒充通信。
- CTF按当前浏览器和任务ID保存节点、手动固定标记及视角，刷新或返回任务仍保留；点击固定标记恢复自动布局，重新整理可清除固定。关系变化只移动相关自动节点，普通进展和轮询不挪动；进行中的位移动画不被轮询停在半程。已完成、取消或归档题目可折叠并通过定位打开。大图初始保留至少70%缩放，用户可全图总览；小图自适配。存储受限明确提示，不声称跨设备同步。
- CTF题目概览突出成员、登记说明、实际工作结论和可展开的关键进展，创建/分配/状态变化收进派工动态；文件使用紧凑标签并按需预览。缺完整前态不补造事件，Lead调度入口读取同一历史来源。“解题流程”展示负责人精简整理及记录/附件引用，缺失、重开旧结论与历史记录如实区分。原始结果依据保留低频只读入口，概览不叠加验证区或最新记录重复入口，不生成完成百分比。

## 对话、记录与隐私

- Bubble与Sender仅替换呈现和输入，仍调用原消息API；保留幂等ID、重试、忙碌状态和Ctrl/⌘+Enter。组件取消/加载不冒充任务已停止或新模型请求。
- Think显示服务实际保存的推理文本/摘要；ThoughtChain显示工具参数和配对结果。已保存checkpoint结果同样可见，正常历史优先；纯推理消息保留。不展示不透明protected_data、encrypted_content、原始回放对象，token计数不编造推理。
- Fact/Intent、任务输入和模型正文使用安全Markdown，不执行HTML、不自动加载外部图片；保留原文入口、代码缩进、独立滚动与长路径换行。上下文、同步注入、工具和实际推理保持来源可追溯。
- 题目工作完成、候选、平台/历史人工/模拟验证与任务终态分别展示。历史验证只读保留；不增加人工确认或修改验证要求入口，不由UI推断通过或生成评分。
- 凭据、cookie、headers和真实任务内容不进入公开截图、诊断文件或提交。样式验证用合成数据；真实页面检查限正常认证后的必要只读访问，不调用模型或靶机测试样式。

## 普通黑板 · 2026-10-15

- 普通黑板与 CTF 共用明亮工作面、蓝色动作、状态图标/文字/浅底及面板密度。保留 Fact/Intent 的依据、推导、争议、认领和结论方向，按选中显示关联；作者颜色仍是产出编码，不代表结论可靠。
- Goal、事实、意图采用紧凑摘要；历史 Agent 默认收起，但作者关联、定位和常驻 Agent 栏仍可打开其会话。默认不展开右侧详情，选择事实进入概览/关联/证据，意图进入概览/执行记录/关联。
- 普通与 CTF 复用同一坐标校验/存储实现，按模式和任务隔离；拖动全节点表面可用，固定标记可恢复自动布局。回放不会覆盖实时坐标，重置请求保留至实际布局完成。
- 动效仅由初始化基线后的实际事件触发，历史回放及减少动态不播放光束；新增拓扑的布局期限不被无关进度延期，异步完成时采用最新状态，不覆写已拖动位置。
- 前端正常事件仅增量推进；旧事件插入或乱序回读仍重建有序投影，回放不可见后续数据。Derive 复用、任务续跑、费用校正有命名事件订阅，未知用量明确提示，不把候选或未定结论涂成成功。

## 动态效果与验证

- Router启用已有的transition支持，懒加载页面在准备好前保留当前页面，AppShell内只设一处Suspense。首次数据读取使用静态Skeleton及可访问名称，不展示“正在加载”等占位文字，也不假装已加载成空列表；后台刷新失败保留已有内容并显示真实错误。运行状态、连接重试、工具执行和保存中的反馈仍保留。
- 页面进入仅160ms淡入，不平移、不由轮询重复触发；CTF报告在新标签打开正式报告页，保留工作台中的未发送会话。
- 使用组件主题的短时交互和面板动效传达加载、状态、展开与关闭；关闭按钮装饰波纹，侧栏宽度变化即时完成，避免文字裁切和反复挤压画布；详情进入仅短时淡入，拖动实时跟随；不增加装饰循环、弹簧、逐字动画，不使用transition: all或无必要的布局属性动画。CTF关系变化允许约450ms局部位移，真实事件光束约1.6秒后结束；普通进展、负责人完成与可信验收的反馈分离，仅可信且非模拟的验收使用成功语义。
- 减少动态偏好关闭组件motion与补充动画，保留瞬时可操作状态。完整响应checkpoint刷新不等于逐token流，不设置虚假的streaming/typing。
- 正式浏览器回归覆盖1440/768/390px与短屏，核对导航、面板调宽/放大、Goal与草稿、视口、推理/工具、表单失败、消息重试、证据、报告、弹窗和键盘。Mock原型不替代正式应用检查。
- 正文对比度至少4.5:1，控件边界和可见焦点至少3:1；不以截图、构建或点击成功推断模型求解效果。未覆盖浏览器、设备与业务边界在最终报告据实记录。
