# 前端视觉与交互规范

依据：PRODUCT.md，Frontend-polish（2026-09-30）。用于维护已有工作台的统一性；运行机制以 docs/design/ 为准。

## 视觉方向

采用浅色产品界面：中性背景承托白色工作面板，深色文字、暖橙色主要动作。字体使用现有系统字体，不下载网络字体。任务图谱中的作者颜色是数据编码，与品牌颜色各有用途；状态同时使用文字、边框和颜色表达。

## 样式来源

- `src/styles/global.css`：语义颜色、字体、间距、圆角、阴影、动画时长、层级。
- `src/styles/controls.module.css`：按钮、输入、标签、帮助、反馈、徽标、加载骨架。
- 页面和组件 CSS Module：功能所需的布局及阅读排版，复用公共控件与颜色。
- 系统字体负责中文正文与控件；`--font-mono` 用于代码、模型标识、系统提示词和原始记录。

## 文字与控件

- 主页面标题26px，次级标题18–20px；表单、控件14px；长篇阅读15px。
- 辅助文字13px，紧凑时间/版本/图谱元数据12px；不把主陈述或输入内容缩成元数据大小。
- 主动作采用橙色实底，次级操作采用中性色，删除采用危险语义色。
- 普通按钮40px、输入44px；手机主要触控区44px，输入16px以避免iOS输入时自动放大。
- 键盘焦点使用明确实线轮廓；错误字段关联错误信息。密码可切换显示，访问凭据仍按平台原有保存流程处理。
- 不新增装饰动画、图标包、字体包、复杂主题切换或新的组件体系。

## 布局与阅读

- 列表与设置使用一致的主标题、间距与导航；创建表单按输入和预算/模型两区组织，窄屏单列。
- 保存操作位于编辑面板顶部；桌面滚动时留在导航下方，手机避免悬浮栏遮住输入。
- 工作台由应用框架分配剩余高度。窄屏详情和Agent对话限制在画布区域，任务动作与Agent切换保持可用；短屏允许页面正常滚动。
- 手机任务列表逐项排列元数据，保留状态、验收、金额、时间和操作，不依赖页面横向滚动。
- Fact/Intent及模型正文使用安全Markdown；模型正文另提供原文，上下文、同步注入、工具和实际推理保持原始记录。代码块独立滚动，代码缩进保持，长路径可以在正文中换行。
- 弹窗使用原生dialog、统一遮罩和视口尺寸限制；保留取消、Esc、键盘与焦点恢复。

## 验证边界

Playwright使用完全Mock API覆盖1440/768/700/390/360px和390×600短屏；验证导航、长内容、保存、原文、对话输入、弹窗和作者颜色。抽检主要文字对比度至少4.5:1、控件边界颜色至少3:1；这些检查不替代完整WCAG认证或真实设备测试。避免以截图、按钮点击或构建成功推断实际模型运行效果。
