# PI 运行时迁移

2026-10-30，用户明确要求以 https://github.com/earendil-works/pi 替换 MAF，并尽量复用 PI 已有能力。本合同替换其他设计文档中关于 MAF 的实现选择；普通黑板、CTF 团队及成果整理的领域规则保持。

## 组件选择

| 能力 | 实现 |
|---|---|
| 多提供方模型、原生多模态、思考、流式、用量 | `@earendil-works/pi-ai`，精确锁定已核验版本 |
| Agent 状态、模型—工具循环、顺序/并行工具、取消与插入消息 | `@earendil-works/pi-agent-core` 原生 Agent/loop，禁止自建替代循环 |
| 现有业务工具、模型准入/计费、黑板同步、执行隔离 | Python 原业务逻辑，通过进程边界的工具/事件回调接到 PI 扩展点 |
| 会话的任务绑定、CAS、投递确认、用量 outbox、代次围栏 | 现有 PostgreSQL 事务为唯一权威；适配 PI 原生消息，不建立第二套任务真相 |
| 持久 Agent harness | 核查 `pi-durable` 的 Storage/重启及工具 replay 合同；仅在能保持未知结果不重放及现有事务边界时采用，不并列运行两套调度器 |
| RPC/追踪 | 核查 `chord` 的现有 JSON link 和 `pi-telemetry`；复用适配范围内的组件，不扩建插件宿主或全局状态服务 |
| 交互 CLI/TUI、本地读写与 bash 工具 | 当前网页平台没有终端交互入口；执行仍通过每任务 envd，不能让 CLI 默认工具操作 agent-runtime 容器 |

`pi-durable` 的官方 README 标为 experimental；其重启会重试被中断的模型请求，工具有独立 replay 规则。迁移不得因此取消平台的未知费用/副作用保护。组件取舍及未采用的原因必须在报告中逐条写明，不能以包名存在推定兼容。

## 运行边界

1. Python 继续管理任务、普通 Explore/Derive/Close 调度、CTF Lead/队友生命周期、成果整理租约和执行容器。PI 负责实际 Agent 循环及模型协议。
2. Node.js >=22.21（PI 库要求22.19，平台使用22.21起的原生环境代理能力） 的受控 PI 进程与 Python 服务同生命周期；不读取用户 `~/.pi`、`.env`、全局提示词/扩展/凭据，也不自动执行任何本地工具。
3. 每次模型调用前完成原有权限/预算准入、提示词更新、黑板/邮箱注入与上下文校验；每次完整模型响应在执行其工具前完成会话及用量持久化。拒绝、不完整流和取消不得派发半截工具。
4. 工具参数由 PI 原生 schema 验证；Python 保留业务参数类型转换与领域校验。明确的可纠正错误作为工具结果，未知写入、控制面失败、执行围栏冲突及无法确认的 checkpoint 必须退出当前运行，不能被 PI 的普通工具异常反馈吞掉。
5. `execute_command` 仍使用已有单派发/幂等身份；取消或进程丢失不能自行重放命令。异步命令的原始 job、generation、drain 和结果通知规则保持。
6. 内部 RPC 按运行/调用 ID 关联，隔离并发 Agent；回调需要背压、取消与断连清理，错误输出不携带密钥、原始请求体或完整命令。

## 会话与兼容

- 已有任务、预算、模型配置、黑板对象、MinIO 档案及原始 MAF 历史不重写、不删除。
- 历史读取适配只转换消息结构；保留工具调用 ID、工具结果、图片引用、来源 ID、思考/签名及 provider 元信息。旧工具配对修复依然不重执行原工具。
- 新消息保留 PI 原生数据，数据库外层 checkpoint/CAS/费用 outbox 维持当前 API 合同。旧格式转换可单独测试，无须安装 MAF 才能读取历史。
- 已结束 Agent 的复盘继续只读。运行中用户消息、Enter 发送和成果整理问答保持现有功能。
- 模型默认值、上下文与最大输出、角色覆盖、价格/币种和 Responses 兼容模式不能因框架切换被静默重置。不支持的旧连接明确报兼容性错误，不擅自换模型。

## 验收与发布

先离线验证 PI 原生循环与回调，再覆盖普通探索/推导/裁定、CTF 派工/邮箱/收尾、成果整理/复盘、图片和流式及用量。测试只用脚本化模型和本机模拟 HTTP/MCP 服务；不调用真实模型、不重跑靶场。

完成标准：生产代码及锁文件不再依赖 `agent-framework-*`；运行链路实际进入 PI 原生组件，不能仅改导入名称或复制 MAF；现有业务回归与新增 PI 集成检查通过。新 runtime 镜像包含锁定的 PI 依赖，启动能明确检测版本及不可用原因。

本轮源码开发不自动切换本地/公网服务。发布时另核验运行任务，在空闲窗口更新，保留数据库/对象存储/配置与可回退镜像；禁止为了迁移中断活动任务或自动续跑历史失败任务。
