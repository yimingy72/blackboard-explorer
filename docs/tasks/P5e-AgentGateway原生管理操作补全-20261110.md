# P5e · AgentGateway 原生管理操作补全

基线 `386958b0a8f0d98c17fe457f1a72d6368bdfdfc1`。固定 AgentGateway 1.7.0（`26f5aebe99a36a037fe54f8080a608aca5547e15`）。原工作区 102 项（30 已跟踪、72 未跟踪）已逐字节和模式独立保留。

用户从「虚拟 API 密钥」新增「演武场」保存返回 405，「LLM 成本」刷新也返回 405。P5a 管理入口只允许模型等部分写操作，P5d 虽修通同源聊天，却需要为每把演练密钥设置部署指纹，原生密钥页面仍不能保存。以实际固定 UI 的调用面补齐入口，保留 AgentGateway 原生配置、身份及成本单源。

## 1. 固定版界面操作与权限

| 原生界面 | 实际请求 | 本轮 |
|---|---|---|
| 模型、虚拟模型、提供商、自定义成本 | `PUT/DELETE /api/config/resources/{kind}[/{id}]` | 保留原生资源及两站空闲保护；接受原生界面合法编码的单段 ID。 |
| 虚拟 API 密钥新增、编辑、轮换、删除 | `PUT /api/config/resources/llm.apiKey`、`PUT/DELETE /api/config/resources/llm.apiKey/{id}` | 允许单个运营者资源；文件及平台密钥只读；保留原生哈希一次展示、原始存储选项、模型权限、预算。 |
| LLM 策略与护栏 | `PUT/DELETE /api/config/resources/llm.policy/{id}` | 允许 `cors`、`guardrails`、`localRateLimit`、`remoteRateLimit`、`timeout` 并使用原生验证、两站保护。鉴权、外部处理和请求转换等影响平台隔离的策略只读。 |
| LLM 成本刷新 | `POST /api/costs/refresh-base` | 调用原生官方刷新；仅支持当前 hybrid 数据库方式，核实自定义费率保留，并确认应用。 |
| 日志、分析、CEL | `POST /api/logs/search`、`/get`、`/analytics/summary`、`/tail`、`/api/cel` | 保留现有读操作，补齐实时日志流并处理断开。 |
| 聊天演练场 | 同源固定聊天 POST；原生数据监听 `POST /v1/chat/completions` | 从原生资源识别运营者密钥，原生验证模型及预算。无按密钥部署配置，不调用用户真实中转模型验收。 |
| MCP、流量拓扑、UI 鉴权、可观测配置、原始配置、安装引导 | `mcp.*`、`traffic.*`、`ui.policy`、`frontend.policy`、`llm.settings`、`POST /api/config[/raw]`；独立 MCP 客户端数据请求 | 部署接管的资源保持可查看或明确不可用，界面不再提示对这些资源执行会失败的写入。业务 MCP 路由、网关服务和端口不改。 |

固定 UI 无独立提供商发现或基准测试写 API。原生客户端接线页应使用可达的外部数据 URL；不能把内部 4000 端口或私有 Service 地址当成公开地址。

## 2. 写入和聊天保护

1. 管理入口按精确来源和原生身份认证。新增运营者密钥仍使用原生单件 PUT，由入口加上原生资源 metadata 归属标识；仅允许更新或删除原生已存在、标识匹配的 UUID。拒绝保留名称、平台 claims、伪造归属，以及与文件或数据库其他密钥的原始值／摘要碰撞。AgentGateway 仍负责密钥生成流程、原生 ID、展示、模型授权和预算；不另建密钥库。操作串行并核实持久结果；原生密钥能热应用，无网关重启。
2. 聊天只在原生 Basic 登录同源页面提供。浏览器手输当前运营者密钥，入口以登录身份读取同一个原生资源集合核对归属，再只把该密钥作为 Bearer 发到原生数据监听。任务、目录和复盘密钥不能替代；不持久化或输出浏览器输入，不共享管理与数据 Cookie，不重试推理。
3. 价格刷新只转发一次原生官方请求。固定版响应有提供商及模型数量，没有目录内容。取得原存储单件 `modelCatalog/default`，确认目录数量、已有自定义费率及其他非基础字段，原存储滚动后按完整资源身份核实，再释放原请求的两站保护。保留未知写入、滚动或解锁保护。
4. 本地独立演练密钥按用户已选的无额度方案，可将模型权限限制到 `BaiZhi/deepseek-flash`。实际值只用原生安全展示交付；未完成展示时不预先生成或在证据中留存可用值。平台原有任务 USD 额度和全站共用复盘密钥保持原样。

## 3. 验证

- 固定版原生 Chrome 在隔离环境实际完成新增、一次展示、演练选具体模型及模拟回复、轮换与删除；验证平台 key 保护和原生模型授权。价格刷新以隔离 HTTPS 合成官方响应验证基础目录及原自定义保留，实时日志验证真实流式消费。必要离线测试及一次 `make check`。
- 用旧工作区快照、原生存储和两站维护回执保护本地切换。现场只做必要的只读验证、经授权的独立演练密钥和官方基础目录刷新；不调用真实付费模型，不读原 `.env`，不改正式设计，不推送。
