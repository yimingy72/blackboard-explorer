# Interactive-agents · 并行发布与持久会话报告

日期：2026-09-27。设计先行提交：`246c5b3`。任务结束后的行为已由用户确认：继续只读复盘问答，不自动重开探索。

## 完成内容

1. **发布与并发**：实际旧任务中种子在350秒运行的第344秒发布Fact，另一Explore在398秒运行的第396秒发布，存在临近结束才提交的行为。通用提示词改为及时共享有证据的中间发现和独立方向，每约5轮且近期无本人发布时提醒检查共享机会；不自动造Fact/Intent，不引入单题清单。已有新Fact、空闲槽位、无待分派Intent且无裁定在运行时，可在Explore仍运行期间派发一个derive；同一事实版本不会重复触发，并行空产不推进静止收尾计数。默认并发上限不盲目增加。
2. **原子派发**：derive登记带明确期望阶段，黑板在任务锁中复核阶段、预算、槽位、事实版本和裁定前置条件；状态变化返回stale_derive并跳过，避免Explore恰好结束造成并行/静止角色错分。single仍关闭derive。
3. **运行中对话**：右侧可直接输入消息，持久队列在下一模型轮次注入真实用户消息。稳定UUID保证网络重试幂等；消息确认与包含该消息的Session checkpoint同事务。结束边界未消费的processing消息即时归队供只读复盘接管，不等租约超时。长命令/已在途模型请求不会被输入立刻中断。
4. **持久Session与续聊**：MAF原生Session逐模型调用保存，初始指令、工具历史和黑板增量保留；结束后恢复同一Session，用get/search/read_evidence只读回答，不执行命令、不写黑板、不改变任务验收。不同Agent最多4路复盘，同Agent串行。复盘用量单独记账。旧任务没有原生Session时基于已存记录初始化legacy会话，并明确说明。
5. **恢复边界**：revision、租约和claim token防重复/旧worker覆盖；PUT已提交但响应丢失会读回对账；工具中断时优先保存真实已完成输出，剩余缺失结果明确标为未知，复盘不重跑旧命令；服务重启后消息可继续处理。
6. **删除与UI**：任务结束/归档不会删除Session。任务列表新增确认删除，终态任务先标记deleting，runtime停止残余清理、销毁容器，再幂等清理对象与DB；失败可重试。前端显示消息等待/处理/送达/失败，历史回放禁发且不泄漏未来回复；显示工作并发和“并行推导”。

## 偏差与边界

- 本次读取`.env`仅由显式测试/部署子进程加载；助手没有查看或修改其内容。所有普通/集成/浏览器测试均无真实模型调用，真实费用仅来自上述隔离检查。
- 历史任务缺失的原生会话不能补造；新会话保留到用户删除。复盘最长180秒、最多8轮工具迭代，费用不混入已结束任务的探索预算。
- 需要重新执行探索时应明确创建新的执行任务，不通过复盘消息隐式重开原任务。

## 运行中答复的收尾回归

修复普通进度答复可能被当作无效回执、从而提前结束 Agent 的边界：只有本轮实际保存并确认了新用户消息，且模型未返回有效回执，才在同一 Session 中提示继续工作或按用户结束要求交接。每批新消息最多触发一次继续；历史消息不重复触发，原时限、步数、上下文和收尾限制仍有效。控制消息使用独立ID，避免连续两轮问答被会话去重吞掉。

新增4项离线回归覆盖进度问答、明确暂停交接、仅有历史消息不重试、连续两批新消息不重复消费；最终普通检查为412项。该边界使用真实SDK与脚本化模型验证，没有为此追加付费调用。补充提交：`Keep active agents running after user progress replies`。

最终集成复跑曾出现44通过、1失败：进程内ASGI测试在取消事件轮询时中断了数据库连接清理，后续请求复用已关闭连接。单独复跑通过，但仍为黑板连接池及该重启场景启用标准的`pool_pre_ping`，在取出连接时检测并淘汰失效连接；不自动重放已开始的写事务。随后完整`make check`为412通过、完整`make test-integration`为45通过，日志保留在交付检查目录。
