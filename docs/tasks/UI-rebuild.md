## 2. 分项交付

### U1：组件、主题与反馈

- 通用控件采用Ant Design的Button、Input、Select、Checkbox、Switch、Table、Form、Tabs、Modal、Drawer、Dropdown、Collapse、Upload等；聊天采用Bubble、Sender、Think、ThoughtChain。
- 单一根级XProvider承接ConfigProvider主题与国际化，antd App提供上下文内反馈。优先token、组件token和公开的styles/classNames，不全局覆盖内部 `.ant-*` 结构。
- 蓝色主要操作、浅灰工作面、白色内容面板、系统字体和紧凑可读的密度统一到全平台；图标来自同一组件库，状态有文字或图形表达。
- 编写组件前用本地Ant CLI的 `--version 6.6.5 --format json` 查询API，再核对官方文档与实际类型，不编造属性。

### U2：B2应用框架与导航

- 可展开的紧凑左导航集中提供任务列表、新建任务、配置中心和最近任务；右上只保留账户及必要上下文操作。
- 根地址进入任务列表；协作画布仅在具体任务详情中作为上下文入口，离开任务后移除。
- 窄屏使用可关闭的导航抽屉，触发器与抽屉ID唯一；保留Esc、可见焦点和关闭后的焦点恢复。

### U3：工作台、详情、会话与Goal

- 默认完整画布，选择Agent或题目后才打开详情。面板支持拖动与键盘调宽、放大/还原、关闭和Esc；窄屏在工作区内全宽展示。
- 保留用户缩放、平移和节点位置；轮询、选中变化、面板开合和查看目标不重置已操作的视口。关闭面板不抢走用户已经转向其他控件的焦点。
- 顶部“目标”在画布列就地展开，默认收起。原目标摘录与可展开全文优先，完成要求或验收条件其次，附件紧凑侧置；背景和约束折叠。缺字段不编造摘要、TODO或结论。
- Goal开合不改变Agent选择、不清空草稿、不重建Session、不增加任务或模型请求。窄屏可暂时隐藏会话抽屉，收起Goal后恢复原选择与草稿；附件预览退出后保留Goal状态。
- 对话保留正文、服务实际返回的推理/摘要、工具参数与配对结果，包括已保存checkpoint但未进入普通历史的工具结果。纯推理消息保留，不透明回放字段隐藏，token计数不冒充正文。
- 题目概览/记录/文件使用现有数据。工作完成、候选、真实/历史人工/模拟验证和任务终态分别展示；记录分页、证据和文件访问保持，UI不生成验收结果。

### U4：全平台业务保持

覆盖登录、任务列表、创建任务、普通黑板与CTF工作台、Worker/CTF配置、模型/MCP配置、Agent对话、证据/工作区、复盘和报告。

- 保留认证、退出、错误跳转及原凭据保存流程；配置编辑保留草稿、版本冲突和显式保存，不因换组件自动发布。
- 保留命名任务、模式、模型版本与能力、预算、初始附件、网络设置及服务端错误反馈。
- 保留消息幂等/重试、成员停止/恢复/移除、任务停止/续跑/删除、归档和历史会话。
- Upload继续接原附件生命周期和API，不新增第二套上传队列；提交与保存期间状态明确，错误后不清空输入。

### U5：正式验证与本地更新

- 执行适用的Python检查、前端ESLint/TypeScript/单元测试、生产构建、Ant CLI lint和浏览器回归；据实际后端变更决定集成范围，不把原型结果记为正式通过。
- 浏览器覆盖桌面、平板、手机与短屏，重点检查导航、Goal与草稿、面板调宽、视口保持、推理/工具、表单失败、消息重试、弹窗、减少动态和键盘。不得弱化旧断言或加长等待掩盖问题。
- 本地平台应实际恢复可用。先核对指定CTF项目服务和持久任务状态；数据库不可用时活动数未知，不假定为零。保留任务、Session、配置、卷与其他项目。
- 优先仅更新静态前端：新资源就绪后原子切换index，不中断运行任务、不重启runtime。需要镜像时只使用当前标签，不新建旧版本回退标签；先完成web build，再打包镜像。
- 正常登录后的真实页面验证限于必要只读访问；不创建测试任务、不发送消息、不调用真实模型或重跑靶机验证样式。最终报告分别列模拟浏览器、真实页面、本地服务与发布证据。
