依据：用户继续优化通用黑板框架的授权；实现架构 6.2（失败应返回原因和修正方法）。从 M5-E2 中独立提取已验证的运行时修复。

## 范围

- MAF 在调用工具前拒绝无效参数时，向 Agent 返回字段路径和可采取的修正动作。
- 保持所有输入、证据、权限和引用校验；保留失败调用记录。
- 用脚本化假模型验证错误反馈、修正后重试及无效调用无写入。
- 不修改提示词、裁定职责、调度、Fact 判重或评测规则；不继续此前被模型服务拦截的评测复核。

## 完成标准

1. make check 与 make test-integration 通过，不调用真实模型，不读取 .env。
2. 报告 M5-tool-feedback-report.md 写明变更、验证、范围和提交划分。
3. 按用户已有 Git 授权合入 main，更新 HANDOFF。保留 M5-E2 的未完成实验分支与原始记录。
