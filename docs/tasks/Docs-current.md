- README 能独立说明 Goal、Fact/Intent、Explore/derive/Close、调度、黑板同步、交接、裁定和终态。
- 有可以照着操作的本地启动与网络排障说明；默认直连和显式代理隔离不混淆。
- 组件和评测 README 不再把已实现功能描述为未来工作。
- 链接、示例命令和文档差异检查通过；提交前运行 `make check`，不调用真实模型。
