# P5a · AgentGateway 模型单源与前端迁移

基线：`1effbcbb0e3d364f24fd33525d4a6760ea3245c7`。方案已独立审查，实施中。原 38 个已跟踪、72 个未跟踪改动隔离，保留历史数据、现有镜像和用户已有服务。遵循总体方案 §11，并按用户最新决定把编辑入口保留在 AgentGateway 原生管理页。

## 1. 交付范围

- AgentGateway 是唯一可编辑的上游连接、凭据、模型路由和成本目录。平台仅显示已应用模型、任务/角色引用及「打开 AgentGateway 管理」入口；不复制 Provider、Base URL、API key、成本编辑器或管理资源写 API。原生管理页用实际支持的管理员认证。未认证的底层管理端口留在可信内部，不通过平台转发原生管理响应或凭据。
- 保留普通黑板 Explore/Derive/Close、原生 CTF Lead/Worker/helper 的已有执行合同，以及既有压缩/摘要入口。把剩余旧模型调用迁到已部署的 AgentGateway；不新建网关或再做协议适配、SSE/价格解析。成果整理继续运行，原 reservation、只读素材和独立预算保留。已结束 Agent 的只读问答及终态复盘继续可发，无费用上限；跨两站使用同一长期专用 review key，费用和求解、成果整理分开。
- 新建 Task、追加金额与续跑、成果整理使用明确的 USD 金额，直接验证网关精度与范围，不需汇率，不把旧人民币默认额改标 USD。历史 CNY、历史冻结汇率（如原先存在）、回放和账单保持；不同币种不相加。命令记录只读，不做审查或处置。

## 3. 最薄实现边界

1. 平台以 `{alias,catalog_revision}` 选模型；服务端读取固定 1.7 的活动 `/v1/models`、原生路由及成本，冻结安全别名、可信路由修订/摘要、成本摘要、能力和 USD 费率。目录读身份只能 GET 模型，不能推理。平台不存或回显上游配置凭据，也不补造缺失能力/费率。任务模型、角色估算和历史显示不授予实际连接权限。
2. 原生 CTF 继续使用原有 NativeFees/NativeAdmin、代理、预算 key、费用证据与派发门；新 v2 环境验收只绑定实际镜像/网络/拓扑，旧 v1 模型绑定不能启用新发布。普通 Runtime 补原 Task/Agent/run/原开始时间/推导轮次及请求摘要的一次发送许可，复用原生 key 读回和费用证据；不持 provider key、不自行解析 SSE 或二次核算上游实际费用。Native CTF 发送与恢复重新核原冻结别名，历史 Task 不借空引用继续求解。
3. 普通 Task 与成果整理各有稳定的原生累计 USD Block key，固定已授权别名，无周期重置。追加/续跑只更新原 key，正向读回同一资源及累计用量后才发布平台额度；金额请求持久去重，不因另一次追加而失效。原生确认应用和是否还有剩余可执行额度分别判断。保持历史估算，与原生实付证据区分，不加成两份。缺实际费用证据为待核。
4. 已结束 Agent 问答和终态复盘共用同一原生 review key，首站用服务身份登记，次站校验同一实际资源 ID；无金额阈值或周期、不得用作活跃求解。普通终态/原生 CTF 复用真实只读会话消费，原请求身份与实际发送回执一一对应，未知不重发。原生费用以来源和日志 ID 去重；分任务可查、管理员汇总两站确认费用，等待费用也包括尚无原生日志的已领调用。
5. 原生管理写入采用实际官方 UI/API；平台只保留需要的站点执行互锁，不替 AgentGateway 管理或发布模型资源。涉及已发布别名/价格的原生管理写入，仅在两个部署消费者都按同 ID 持久关闭新建/新发送/恢复、没有活动引用或未确认在途调用时可进行。失败、缺席不写；结果不明不重发、不放行旧快照。新任务读取目录与最终事务用同一个维护代数核对，避免在完整维护期间冻结旧价格；已停止历史记录不永久占用维护。具体认证/原生写互锁用实际固定版本验证，不引入第二个配置源。

## 4. 验证、部署与分工

- Core：共享 Task/模型合同、BB 安全目录、生命周期/费用准入与历史、Web 原生管理入口、生成物和报告。Runtime：固定 AgentGateway 官方管理能力、旧实际发送迁移、原生控制薄改动与必要隔离实测。独立 reviewer 审合同、源差量、最终候选和原 WIP 保护。
- 必要验证：浏览器实际打开经认证的原生管理页、平台不出现编辑表单或旧写端点；真实 AgentGateway 合成路由在两站只读可选，新 Task 提交明确 USD。实测普通角色发送/预算阻断后不触达上游、同 key 追加与续跑、Progress 独立调用、两站终态及运行中 Task 的已结束 Agent 使用同一 review key 真实问答。维护只验证最小空闲成功与活动/丢失 ACK 拒绝，账本验证复盘不进入求解费、历史人民币不重标、无日志调用仍待核。原生 CTF 使用一条实际新发布路径验证真实原生发送链；不调用付费模型。最终干净候选运行必要验证及 `make check`。
- 本地更新只操作此前独立平台，先复核活动 Task、备份自有卷/配置，保留用户新数据、十个旧交付镜像和旧 OpenSandbox 服务。用户业务环境不留测试模型或假可用状态。未配模型可登录并进入原生管理；原生环境没有确证时不假装可创建。不读原 `.env`，不改全局设置、AGENTS 或正式设计，不推送。
