# 模型配置删除

基线：main@2b49dd5。复用干净工作树platform-performance-audit，在feature/model-config-delete分支实现。

用户要求模型配置支持删除。本任务只扩展模型注册表与对应页面，沿用既有权限、Ant Design确认弹窗及版本化凭据，不改模型调用、MAF或执行环境。

- 删除操作从模型列表和新任务选项移除连接；默认模型删除后取消默认，不替用户选择替代模型。
- 保留旧任务固定版本及加密凭据，以支持运行、续跑及复盘；删除不等于向厂商吊销密钥。
- 不允许新任务通过旧模型版本或旧Profile绕过删除；Worker提示词编辑仍可使用既有模板。
- 重复删除幂等；保存/删除/默认设置通过既有Postgres事务锁协调，删除后保存不得复活同一连接。
- 数据库0018增加删除标记；启动初始化不能重新创建已删除的内置连接。
- 校验权限、历史快照/预算/凭据保持、两模式旧选择拒绝、并发操作与前端确认/失败/空态/窄屏交互。无真实模型调用。

三份设计正本不修改；本次补齐原配置中心未定义的删除生命周期，以本说明与报告记录最小兼容规则。
