2026-10-19 用户要求：成果整理和运行任务的 Agent 输出与模型配置对齐；完善模型 ID 获取/选择、默认 1M 上下文、输入输出与能力参数配置；先寻找成熟组件和接口，尽量复用 MAF、已有 SDK 和前端组件。
