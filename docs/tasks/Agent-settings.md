# Agent-settings · 配置页重设计与模型上下文

## 范围
用户要求主会话亲自设计实现前端；后端可委派。先读 AGENTS.md、Worker-settings-report、Runtime-continuation-report 和两份设计正本的新增上下文段落。

1. 平台模型改名模型配置；统一三入口导航、角色标题字体、布局间距、提示词编辑器、工具列表、模型/MCP表单和响应式显示。删除不再使用的历史布局样式。
2. 平台模型新增可选 context_window；正整数且拒绝 bool/小数，null 兼容旧配置。新任务输入交接阈值按最小显式模型窗口80%计算（至少1），覆盖旧阈值并同步profile快照；旧任务/续跑不改变。
3. 保留提示词下一次模型调用生效、模型/工具新任务生效、密钥只写、并发编辑冲突保留草稿。
4. 运行 make check、make test-integration、web检查/构建/浏览器回归；使用模拟数据做桌面与手机截图审查，不调用真实模型，不读.env。
5. 写中文报告，含实际验证与部署限制；部署前检查活动任务，避免中断用户正在运行的任务。
