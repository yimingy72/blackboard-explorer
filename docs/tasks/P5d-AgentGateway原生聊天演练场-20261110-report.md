# P5d · AgentGateway 原生聊天演练场报告

## 完成内容

P5d.1 确认「应用 CORS」的 405 来自现有管理入口对原生策略写入的限制。原生界面还会从容器端口推导 `http://localhost:4000`，而本地开放的是 `http://localhost:15814`。15814 是 HTTP 数据转发，私有原生管理的 HTTPS 证书不用于该端口。

P5d.2 保留固定 AgentGateway 1.7.0 的原生聊天页面和中英文切换。聊天走现有入口的同源请求，省去原先失败的 CORS 操作。启用时只接受手输的独立演练 Bearer；原生模型、密钥权限和数据监听仍由 AgentGateway 执行。页面与模型管理继续使用原生 Basic 登录。转发仅限固定聊天路径、精确来源和专用密钥，管理和数据连接不共用 Cookie，不跟随重定向、不重发请求。受保护的原生配置保存仍与转发互斥。

P5d.3 本轮按用户选择只修入口：尚未配置演练专用密钥时，页面直接说明原因，发送关闭。已有模型和提供商、原生配置和存储、平台任务 USD 额度及两站共用的独立复盘密钥保留。未发放密钥、未改 CORS、未开放策略或密钥写入、未在用户环境发送推理。
