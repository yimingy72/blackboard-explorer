# 登录后返回登录页修复报告

日期：2026-10-15。工作树 `/Users/yym/bbx-wt/ui-rebuild`，分支 `fix/login-session-cache`。

## 原因与修改

真实后端用现有配置执行正常登录返回200，Cookie为HttpOnly、路径 `/api`，携带Cookie读取任务返回200、13项任务。没有读取 `.env`，凭据和Cookie值仅留在测试进程内存，未输出或写入文件。

前端问题可以独立复现：先展示带数据的任务列表，再模拟会话过期返回401。页面跳转登录后，原查询错误仍在 QueryClient 中。再次登录虽然成功，挂载任务页时旧401仍触发跳回登录页；随后的成功响应不会自动把页面带回来。

`LoginPage.tsx` 现在在成功登录后、导航前调用既有 `queryClient.clear()`，与退出登录使用同一公共组件能力；同时移除上一会话的查询和错误。账号校验、Cookie、原目标路径和失败提示保持。没有新增依赖或另建会话系统。
