# Agent 手动对话与回车发送修复

## 目标

修复公网 HTTP 部署中两种模式无法发送手动消息的问题；任务运行时，已结束的普通 Agent 也可复盘问答，运行中的 Agent 接收定向消息。Enter 发送、Shift+Enter 换行，保留 Ctrl/Command+Enter；中文输入法确认不能误发送。

## 范围与边界

- 复用现有 Ant Design X Sender、MAF Session、消息租约及只读复盘工具，不新增依赖。
- 检查所有同类 UUID 调用，避免公网 HTTP 下附件、续跑和成员操作再次失败。
- 放开普通 Derive 的任务内复盘时，以数据库锁和有效消息租约保护同一 Session；调度器等待复盘结束再复用 Agent。
- 保留 CTF 成员主动停止、移除、收尾及历史回放的现有执行边界；发送消息不自动恢复用户停止的成员。
- 保留数据、预算、配置和存档；部署仅在没有活动任务或复盘时切换，不调用真实模型验证。

## 完成标准

1. 两种模式的按钮和回车发送兼容没有 `crypto.randomUUID` 的浏览器环境。
2. 运行中和已结束 Agent 的输入可发送；普通 Derive 的只读回复不改变黑板、预算或 Agent 执行状态。
3. 会话复用与复盘互斥，过期请求不能覆盖新执行；失败重试沿用消息 ID 与草稿。
4. 前端检查、生产构建、相关浏览器及后端回归通过，写中文报告。
