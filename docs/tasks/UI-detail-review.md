# UI-detail-review · B2 使用细节复核

用户实测指出动画、布局、任务列表字段和详情导航仍不合理。本轮沿用B2，在现有工作树的 `feature/ui-detail-review` 分支修正使用流程，主会话负责界面设计与源码，GPT‑6.1 Sol high子代理独立复核与浏览器回归。

- 稳定全局导航，任务详情归属任务列表，不插入新的当前页菜单；内部路由保持应用框架。
- 列表围绕名称/ID、模式、运行状态、已记录费用/预算和耗时组织；终态不冒充目标达成，未知数据不补零。窄屏直接展示信息和操作，搜索/分页往返保持。
- 修正助手记录阅读宽度，终态报告入口、辅助文字与有目的的短时反馈。
- 首次打开详情、目标和导航时保持画布视角；新增关系不移走已有节点。断点变化保持会话DOM、阅读和展开状态，覆盖的画布不进入键盘焦点。
- 保留B2和已有API、认证、配置、会话、幂等、附件、归档、验证与任务规则。不改docs/design、不调用模型、不读.env、不新增框架或依赖。

先独立审查路径和截图，再做静态扫描；自动结果不代替设计判断。最终执行前端检查/构建、适用的普通检查、隔离浏览器回归并实际查看截图，记录问题、修法与未覆盖边界到 `UI-detail-review-report.md`。本地仅更新静态资源，不重启正在使用的runtime或改变任务数据；发布提交另按用户指令处理。

2026-10-11 补充：用户要求继续审核其他前端细节。本轮检查配置编辑和离开保护、模型必填价格、MCP 工具预览、CTF 工具解绑、新建任务缺模型引导、初始附件、历史轮次工作区、报告错误恢复和加载状态。保留 B2 视觉方案，通过真实操作路径修复问题，不增加新的产品能力或后端规则。
