# 多任务并行运行

依据：用户 2026-10-17 要求“修改平台允许多任务同时运行”；实现架构第 5、11 节，开发方案部署条件与环境配置。

## 范围

- 复用已有 TaskSupervisor、任务独立执行容器和 MAF Agent，不增加调度框架、数据库表或 UI 配置入口。
- 默认任务并发从 1 调整为 2；保留 MAX_RUNNING_TASKS 正整数覆盖及超额 FIFO 排队。
- 普通黑板与 CTF 可以同时运行；验证启动中、运行中、清理中的容量计算，以及终止一个任务不影响其他任务。
- 更新部署说明和本地 runtime；保留现有任务、会话、平台配置、PostgreSQL/MinIO 卷。不自动启动用户任务或调用真实模型。

## 完成标准

1. Settings、Compose 和示例配置使用一致的默认值。
2. 离线回归覆盖两模式及混合运行、容量用满、释放后补位、重启恢复。
3. 运行相关 Docker 集成检查，确认不同任务的执行环境和文件不串用；测试只用脚本化模型或无模型路径。
4. make check 通过；检查与部署实际结果写入 Multi-task-runtime-report.md。

## 设计同步

本需求明确替换原“同一时间一个任务”的部署限制；先单独提交实现架构、开发方案与本任务合同，再修改运行配置与回归。
