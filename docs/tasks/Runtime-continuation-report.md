## 需求与实现

- 看图：采用 MAF 原生 `Content.from_data`，新增 `view_image`。Explore 可读本任务工作区；derive、Close、只读复盘可读同任务证据图片。PNG/JPEG/WebP、单图10MiB，拒绝跨任务及非法路径；图片按散列存储，Session 保存引用，在模型调用时恢复图片数据。已知不支持的 Bedrock 连接器和 DeepSeek V4 Pro 明确反馈；其他接口仍需模型本身有视觉能力。
- Derive：同任务复用一个逻辑 Agent、原生 Session 与累计贡献/用量，后续每轮接收新控制信息与黑板变化。必要完成复核规则保留，本轮回执只核对本轮意图。上下文过大时切换模型输入段，完整旧会话仍保留；该切换会牺牲一次前缀复用，避免无限扩大上下文。
- 大证据：模型 get 默认 depth=0，按需 depth=1；read_evidence 默认16,000字符/页，最大32,000，标明下一偏移。完整文件没有截断或删除。通用工具行为适用于全部任务。
- 续跑：用户显式填写追加金额/分钟，增加原总额度；保留同任务黑板、证据、会话，恢复归档文件。累计活动时间不计暂停。旧报告/归档按轮次保留，复盘不会隐式执行。可选择把当前 Worker 工具设置固定到新执行轮次，便于旧任务使用看图；模型、目标与验收保留。
- 计费：固定费率与官方 DeepSeek 峰谷模式可选；新调用记录请求开始时刻、有效费率、倍率与规则版本。推理是输出的子集，不重复计费；金额用 Decimal 累计。历史重算先预览、再追加 `cost.reconciled` 审计事件，原 token/用量事件保留，重复应用不重复扣减。只读复盘逐调用费率与模型响应在同一 Session checkpoint 保存。

## 边界与待决

- DeepSeek峰谷规则核对于2026-09-28，节假日日历覆盖2026年；未知年份工作日峰时保守按高峰价估算。其他厂商保持填写的固定价格，Anthropic/Bedrock缓存写入当前仍按普通输入估算。
- 旧调用没有请求开始时间时，校正按用量事件时间估算；跨时段边界可能不准确。运行中服务异常导致模型响应或心跳用量丢失，估算也不能替代供应商账单。
- 归档恢复针对工作区文件；系统安装包、后台进程及网络连接不恢复。符号链接与硬链接不恢复，弹窗明确提示，恢复接口返回跳过数量并记录运行日志。
- 图片二进制不会进入Session快照；当前按需从对象存储恢复模型所需图片，没有新增图像处理依赖。很多历史图片仍会增加请求传输和上下文开销。
- 分段发生在derive轮次间；完整历史仍供复盘。非常长的单轮或复盘仍受所选模型上下文上限约束。
- 本轮脚本化回归能证明调度、持久化、计费和恢复机制，没有进行新的收费目标对照实验，不能承诺实际完成时间或缓存率提升的百分比。

## Derive开发核验

- 迁移 `0008_derive_reuse.py` 在 `agent_runs` 增加 `derive_round`、`round_start_version`、`previous_receipt`；`agent.reactivated` 更新同一行，保留累计 steps、usage、last_seen_version，重置本轮状态。
- 登记与复核仍受任务行锁和最新版本门控；本轮回执只核对 `version > round_start_version` 的本Agent Intent。并行推导以正常结束轮次的 `last_seen_version` 避免重复处理已读Fact。
- 后续轮次向同一原生 MAF Session 追加模式/版本/验收控制消息；运行中黑板变化附在尚未发送的新用户消息或工具结果，先前已发送消息保持稳定。
- 上下文超过阈值时，同Session保留完整历史供复盘，模型历史提供器从新段读取并刷新黑板上下文；没有静默删除旧消息。
- derive JWT包含轮次；agent写接口、heartbeat、finish、工具日志、trace、Session保存、conclude/grace均在任务锁内核对轮次。缺省轮次按第1轮处理；Sweeper取消也核对当前协程轮次。
- 运行中已结束derive不进入只读复盘待处理队列；已结束Explore仍可复盘。
