# 通用黑板前端与架构优化

用户要求：在此前 CTF 工具错误修复完成后，参照已认可的 CTF 前端风格、配色与动效，重构普通黑板前端，同时审核普通架构代码并优化性能。

前端在 `ui-rebuild`，后端/运行时在 `ctf-cooperation`，直接沿用现有在办分支并保留全部历史改动。主会话设计并实施前端，GPT‑6.1 Sol high 子代理负责普通模式后端，主会话交叉审核。

## 实施范围

- 沿用既有明亮工作面、白色面板、蓝色操作、紧凑布局及 Ant Design/React Flow；状态带文字与图标，默认画布、点击展开详情。
- 普通 Fact/Intent/Agent 节点、关联/证据详情、原生上下文/思考/工具对话统一；按需关系及真实事件短时光束，不播放历史假通信。
- 坐标、手动固定与视角按模式、浏览器、任务隔离保存，刷新与面板开合不重置；历史回放不覆盖实时布局。
- 普通事件推进不反复重放整份历史，布局相等比较线性化；保留回放、重复与乱序事件的正确性及未修改对象引用。
- 审核 state 快照一致性、无用工具日志加载、会话元数据读取及事实依赖计数，保持写规则、鉴权、争议深度与引用去重。
- 修复可复现的工具不确定结果重试、启动恢复短断退出、成功模型用量未持久化；优先 MAF 公共组件和现有 Session、事件、heartbeat 接口。

## 完成标准

保留通用 Fact/Intent/Explore/Derive/Close 语义、任务/会话/模型配置及存档；不修改 `docs/design/`、`.env`、真实靶场或密钥，不调用真实模型，不执行 Git 写入。

前端 lint/type/unit/build 与适用 Mock 浏览器回归通过，Python `make check` 与复用镜像的隔离集成通过；将实际性能操作数、字节数、验证与限制写入 `Blackboard-refresh-report.md`。本地发布先确认写入状态，保留现有数据；仅静态更新不需要中断真实任务，后端更新只在安全检查点进行。
