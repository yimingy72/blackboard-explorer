## 1. 实现范围

1. 单 Node.js 进程、本地 SQLite 黑板、事务后事件通知与调度。覆盖首次分配和后续自主领取、同级主援、Fact/Intent、核验、暂缓恢复、累计解题提醒、版本和幂等。
2. 初始 20 个持久 Pi Worker 会话。Lead 读取容器实际资源并决定增员，创建回执准确，复用会话上下文。按已确认方案采用简化容量管理。
3. 固定 Pi SDK、本地命令及文件工具、明确角色与工具路径的系统提示词、实时 steer、输出日志、正常退出收尾与重启回读。
4. 正式求解接口适配与独立启动入口，处理题目、附件、环境名额、候选、flag 提交及真实回执、整场终态。
5. 完整比赛镜像集成。先估算新增依赖和总大小，再验证实际导出制品小于 3,000,000,000 字节，并复测实际工具与求解流程。

## 2. 目录与分工

实现位于 `services/ctf-standalone/`。黑板、Pi 会话与工具、赛事适配分别由子代理并行实现，主代理负责协调器、入口、资源读数、完整流程与组合负载、镜像整合和复核。共享根 `Makefile` 仅增加独立程序检查入口。内部 Node 数据结构属于此单体程序，跨服务合同继续使用 `packages/contracts` 的原有定义。

- `make check` 包含原平台回归和新增独立程序离线测试。
