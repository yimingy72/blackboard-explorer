# 平台维护修复交付记录

本次从 GitHub `main` 的 `55044a9` 开始，合入平台工作区的会话读取和归档读取修复。

## 变更

- 任务进入复盘时立即刷新消息与会话记录。服务端标记会话仍在同步时，页面继续读取，收到最终记录后停止轮询。
- 报告和工作区通过同一解析逻辑检查任务读取权限、运行轮次和对象归属。补充回归测试，覆盖当前报告、历史报告和跨任务对象拒绝。
- 已绑定附件的列表和下载沿用任务读取权限。读取时核对任务模式，CTF 成员另需通过当前代次的校验。
- 私有挑战和记录事件按收件范围投影。范围以外的成员只收到用于推进读取位置的游标。
