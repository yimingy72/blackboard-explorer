# P8 · 配置工作台与角色合同

将已确认的五页预览落实到 P7 单站点：普通 Worker、CTF、成果整理、模型、外部 MCP。沿用已有账号与任务数据；不迁库、不增加目录写权限、不重跑历史任务。

1. 普通 Worker 按真实探索、推导、裁定角色显示平台工具；探索的命令与读写文件统一开关。可配置工具使用真实参数、必要性及权限分组；外部 MCP 仍须明确选取。普通提示词、工具与调度设置发布为新任务版本；任务与续跑沿用原快照。改写现行角色系统提示词并保留领域规则、模板变量、证据、裁定、预算、交接与结束约束。
2. CTF 展示部署已发布的 Lead 与 Worker 及对应工具合同，不增加网页发布或权限写入口。角色提示词对齐真实发布工具，Lead 只在部署允许时选择任务网络，Worker 不改变任务网络；平台强制网络不能关闭，命令与逐 Agent 流量留痕。发布追加版本并更新部署引用，保留原验收回执与镜像。
3. 成果整理独立展示提示词、受限平台工具与模型。提示词与工具变更用于下一整理轮；模型首次启用时冻结，费用按整理独立预算结算。树更新不能修改任务求解黑板或终态。
4. 模型维持 OpenAI 兼容协议、四项 USD 每百万 token 费率；连接测试允许未定价，任务使用仍受凭据、能力和定价校验。
5. 外部 MCP 使用公网 HTTPS Streamable HTTP：草稿、发现、明确选择工具和允许角色、发布。发布不代替任务授予；继续限制 Explore、CTF Lead 与 Worker；无删除或自动发现。
6. 用角色合同、版本与 PostgreSQL 定向检查、全仓检查和浏览器只读验收；不请求真实模型。正式更新保留现存自定义配置、原站点存储、Runtime 与 CTF VPN 验收。只同步交付分支。

默认模板更新按角色比对已知上一版内置正文，只有精确匹配的才替换；不改历史行或覆盖用户独立编辑。成果整理显式自定义优先，默认正文由新轮次认领时选用。回退使用保留的应用与 CTF 发布文件，已追加的不可变版本不回写。
