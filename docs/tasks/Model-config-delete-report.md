# 模型配置删除实施报告

日期：2026-10-18；基线main@2b49dd5，分支feature/model-config-delete，复用工作树platform-performance-audit。

## 完成内容

- 模型配置页顶部新增删除按钮，使用既有Ant Design确认弹窗。提示是否删除默认模型、是否丢弃未保存草稿；取消不修改，失败保留草稿并可重试。删除中锁定表单/页签；成功后选择剩余模型或显示空态。窄屏连接选择区不再被操作按钮挤窄。
- 新增鉴权的`DELETE /api/platform/models/{name}`，返回204，重复删除幂等。使用0018迁移添加`platform_configs.deleted`；从可选列表移除所有版本，但保留历史快照及加密凭据。
- 已有任务、续跑和复盘继续按原固定版本获取凭据；不改任务、预算、消息或归档。旧浏览器显式指定已删除版本、普通旧Profile及CTF新任务均不能绕过删除。
- 删除默认模型会取消默认设置，不自动选择另一厂商或模型；没有默认时接口给出明确选择提示。启动初始化不会恢复已删除的内置连接；普通Worker提示词仍可编辑。
- 保存、删除和设置默认模型沿用Postgres事务锁，删除后旧页面保存不能复活连接。不新增依赖，不改变MAF模型调用层，不扩展MCP删除功能。
