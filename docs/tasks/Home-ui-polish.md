# 首页与全平台交互整理

用户要求：美化平台首页、重排任务列表、优化页面跳转，移除跳转时可见的加载文字；优先采用项目已安装的Ant Design组件，并检查其他前端页面。

- 沿用用户确认的明亮B2风格，主会话设计及实施。首页以Listy、Segmented、Tag、Dropdown、Pagination等现有组件构建紧凑列表，保留搜索、短ID、模式、状态、币种/费用、耗时、分页及删除确认。
- 页面切换保留已显示内容，统一首次读取的Skeleton反馈，保留可访问状态、真实错误/重试及实际运行/连接状态；不通过延迟或假进度掩盖请求。
- 审查创建、配置、报告、会话、文件与普通/CTF工作台；修复不一致的手机边距、触控区和输入字号。
- 不改后端、模型、提示词、用户数据、`.env`或`docs/design/`。使用合成数据验证桌面、平板、手机、加载、失败、搜索/分页/返回、草稿与登录，静态核对减少动态规则。
- 完成后记录检查、浏览器证据和限制，再更新本地静态界面及对应镜像供用户测试。
