# P5b · AgentGateway 原生管理中文化交付报告

## 完成内容

P5b.1 将 [AgentGateway PR #2593](https://github.com/agentgateway/agentgateway/pull/2593) 的简体中文资源和语言切换移植到固定版 AgentGateway 1.7.0（`26f5aebe99a36a037fe54f8080a608aca5547e15`）。社区 PR 未合并，取其明确来源 `c13b1eb06fd3e966150d3b566ce36a2636ebcdf8`。原 PR 有 78 个 UI 文件，45 个文件不能直接应用到固定版本。最终差量涉及 80 个 UI 文件，以固定版的表单、模型和密钥标识、密钥轮换及策略逻辑为准，只移植呈现层，新增两项固定的 i18n 依赖。核对的 2,719 个上游非 UI 文件及符号链接完全一致；保留 Apache-2.0 许可证和上游归因。

P5b.2 从平台的「打开 AgentGateway 管理」进入同一个原生管理入口。页面右上角可切换「简体中文 / English」，初次打开会参考浏览器语言；显式选择可跨刷新保留，切换不丢当前表单草稿。主要入口为「模型」「提供商」「成本 → 自定义成本」「虚拟 API 密钥」。原生配置写入仍用原生表单，模型和提供商标识、枚举、费率数值按原值提交。虚拟 API 密钥仍由平台管理，既有写入限制不变。

P5b.3 以现有已鉴权入口提供固定版官方 UI 构建产物。所有本地 UI 资源先通过原生 Basic 认证；仅匹配的 GET/HEAD 页面和静态资源可走本地构建，缺失资源返回 404。现有 API 转发、密钥与结构写限制、两站空闲互锁和原生配置读回仍走既有路径。可选 UI 层不改变原生 AgentGateway 二进制、数据库、配置或持久卷。保留原入口镜像，可独立回退 UI。

## 偏差与待决

社区 PR 不直接兼容固定版，未降级固定版的依赖或复活已经删除的预览模块。中文覆盖主要原生工作流；后端返回的部分错误、外部帮助和未覆盖的界面文本仍可显示英文。无需修改正式设计文档。产品使用范围与模型是否已配置无关；验证过中文页面不代表已配置真实上游模型。现场曾有一次 Provider 保存已落库但页面提示错误；本次切换前读回 1 个 Provider、0 个模型，既有维护保护不由 P5b 解除。后续保存仍可能被既有保护阻塞，本任务不修复那次保存或重试配置。

后续升级 AgentGateway 时，先检查上游 PR 是否合入对应固定版本，并用同一窄验证确认语言偏好、模型与成本保存和密钥写入限制；若已有正式内置资源，可以移除本地补丁与静态覆盖层。
