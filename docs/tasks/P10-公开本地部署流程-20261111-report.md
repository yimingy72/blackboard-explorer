## 偏差与待决

- 本次不是新集群安装，也不是切换到新业务镜像。维护工具提交、现运行镜像源码及报告提交是不同版本。实际执行成功，未触发恢复路径；漂移、在途任务或旧 Pod 未退出时拒绝继续由定向测试覆盖。
