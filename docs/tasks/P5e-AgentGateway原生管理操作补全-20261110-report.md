## 偏差与待决

隔离验收的模型与成功刷新链路使用合成响应，不能据此确认用户中转服务的凭据、连通性或实际费用。现场官方基础目录未更新；当前固定版不兼容已复核的官方目录格式。本次纠正只更新诊断记录，未升级网关、改动网络或导入改写的目录。官方基础目录不代表中转商的实际报价；中转商的实际费率可在原生自定义成本处配置。共享平台的鉴权、转换、外部处理、全量配置和网络拓扑继续由部署管理；独立 MCP 开通不在本轮。未改正式设计或原 `.env`。
