# 成果树与成果整理 Agent

依据：用户2026-10-18批准的 [方案](../proposals/Blackboard-progress-tree-design.md) 与 [设计合同](../design/成果树与整理Agent.md)。

## 范围

1. 任务级成果投影、候选图事务、来源引用、分页截至版本、目的鉴权、独立预算/费用预留、会话/消息/租约、迁移0019。
2. 复用MAF实现整理Agent及结构化工具、增量全局梳理、稳定Session、问答、恢复、请求用量结算；不加入求解调度。
3. 普通黑板同任务成果树入口与明亮树状画布；可读总览、节点详情、关键过程、来源、贡献与对话；复用现有组件和布局能力。
4. 创建页显式整理开关/独立上限，旧任务可显式启用；成果角色设置支持提示词和现有平台模型。
5. 生命周期/归档/删除/续跑，脚本和隔离数据库/浏览器验证；本地/公网更新前确认无活动任务，保留预算、配置及数据。

## 内容标准

意图只是组织线索，必须按整体目标归并同义方向、关联跨意图的因果与排除结果。总览回答现在知道什么、主要缺口和下一步；节点写清具体子问题、做过什么、发现什么、重要性、限制和后续，不用空泛状态充当内容，不逐Fact搬运。关键过程与结论带来源，数据量大时有界批次持续推进，不跳过未处理记录声称全局追平。

## 验收

权限不能写求解数据；图和问答幂等、同Session串行；跨任务/旧轮/过期租约/CAS非法均拒绝；未知调用不盲重试或释放费用；progress事件不影响solver；原黑板/CTF回归保持；大批量来源、争议变化、局部布局及历史可读；部署不停止活动任务或覆盖现有数据。
